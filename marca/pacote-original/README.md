# Pacote de identidade digital — CONECTA

Pacote baseado na logo fornecida, preservando desenho e proporções.

## Arquivos
- logo-master-1024.png — master transparente.
- logo-web-512.png — uso geral na interface web.
- pwa-icon-192.png / pwa-icon-512.png — PWA/web app.
- android-app-icon-192.png / android-app-icon-512.png — ícones Android com fundo grafite.
- android-adaptive-foreground-432.png — foreground do Adaptive Icon.
- android-adaptive-background-432.png — background do Adaptive Icon.
- android-notification-icon-96.png — versão monocromática para notificações Android.
- favicon-16.png / favicon-32.png / favicon-48.png — favicon.

## Cores predominantes
- Azul: #2B54A3
- Grafite: #373435
- Branco: #FEFEFE

## Regras
1. Não distorcer a proporção da marca.
2. Manter área de respiro ao redor do símbolo.
3. Para notificações Android, usar a versão monocromática.
4. Para app/PWA, usar os arquivos quadrados.
5. Para web, usar a versão transparente quando houver contraste suficiente.
